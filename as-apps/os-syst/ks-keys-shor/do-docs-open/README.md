# One-Tap Keys

Turn your unused keys into one-tap shortcuts: F1-F12, Insert, Home, End and more. Windows only.
No cloud, no account.

## What you get
1. One key does one common job: find, save, copy, paste, undo, new tab, close tab.
2. Forget a key? Press the **Menu** key. The full list shows on screen.
3. Double-tap **End** to shut the PC down the safe way (you can cancel).

## Requirements
Windows and AutoHotkey **v1.1** (not v2). Get it free at `autohotkey.com/download/1.1/`.

## Quick start
1. Install AutoHotkey v1.1.
2. Run:
```
"C:\Program Files\AutoHotkey\AutoHotkey.exe" "E:\zz-base-home\as-apps\os-syst\ks-keys-shor\ru-keys-shor.ahk"
```
3. A green **H** icon shows near your clock. The keys work now.

To start it at every login, see `HOW-TO.md`.
